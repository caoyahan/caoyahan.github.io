饮酒

发表于 2026-08-11 分类于 文学作品

2022.7
（仿）

俱往矣煮酒青梅绕，分袂又经秋。渐霜风凄紧，关河冷落，残照当楼。门前济水接天流，人间如掌山河影子，斟入杯中。
浮生长恨醉时少，苦山抹微云，忽尔苍狗。把梅妆拭了，和天也瘦。古来大梦戥春秋。曾几时凭栏夜话归路：不可泛舟学范蠡，当取一流。

明湖夜宴逢故人歌

发表于 2026-08-10 更新于 2026-08-11 分类于 文学作品

2023.5

庆丰二十二年秋，张昊出差谈项目，从济南府鲁采历下亭逢余故人孙文雅，忆往昔时日，余尚童稚，曾于实验许其诺。秋千，操场，大明湖畔，犹在眼前。欲问其所适，何致于此，念及旧意，恐不相认。谁料孙文雅竟在王总席前提及此事，张昊又搭话失言，公事作吹，抚事慷慨，遂作此篇。
明湖秋夜旧时月，从鲁采宴历下亭。
金鳞烩鲤乌参羹，银盘玉箸不忍食。
座中忽报佳宾至，半卷珠帘掩翠屏。
胸前白雪好风色，低眉自道慕王总。
三巡已过谈锋健，百万公事仰赖卿。
自言家本泺口住，曾隶山师附学名。
一朝新冠疫疠劫，慈亲卧病弟伶仃。
弃学忍作樽前客，夜场直播幸扬名。
今宵醉后言多忤，乞恕狂疏莫见刑。
座中廉某忽惊起，急前附耳低声语。
王总拂袖掷盏去，“旧同学干我甚事？”
惊得酒醒推门去，千里经十彻夜明。
车水马龙流光碎，曾照书窗寒夜影。

高考后夜行过工地有感

发表于 2026-08-10 更新于 2026-08-11 分类于 文学作品

2024.8
疫情后，济南东部工地遍布、开发放缓

吊塔凌空摆，夜班人初上。
盔下斑驳草，石灰还白首。
堂堂中国速，赫赫不眠人。
问教苦如此？叔停炒面箸。
“若非施工地，何以资儿学！
年幼少无知，老来考编迟。
吾表侄儿阔，华为五百强。
又娶公家女，饭碗米粒香。
无求中彩票，惟愿子如龙！”
语罢饮青啤，同道重唧唧。
“白班九十五，夜班一百七。
勤工日日俭，十年即首付。
大儿二十七，卖地置彩礼。
小儿十有九，一月一千一。
家中贷未尽，我先白首已。
人生得如此，岂可空叹息。”
工地尘扬扬，草木尽戴孝。
明明新绿上，遥似螨蚧生。

有梅萋萋，其实赫赭。

足之蹈兮，梅也舞之。
